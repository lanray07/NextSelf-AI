# NextSelf AI

Premium SwiftUI iOS scaffold for an AI-powered personal transformation app.

## Build

Open `NextSelfAI.xcodeproj` in Xcode 16 or newer, choose the `NextSelf AI` scheme, and run on an iOS 17+ simulator.

Mock AI is enabled by default through `MockAIService`. The remote endpoint placeholder is in `NextSelfAI/Services/AIService.swift`.

## Included

- SwiftUI NavigationStack and tab shell
- MVVM-style `AppModel`
- SwiftData models and local model container
- StoreKit 2 subscription scaffolding
- Speech-to-text and recording service placeholders
- Voice journal with waveform animation
- Future-self chat and engine
- Daily missions, check-ins, timeline, analytics, identity levels, comeback engine, habit builder
- Native share sheet and PDF progress export
- WidgetKit and Apple Watch placeholder screens
- Wellness disclaimer and safety language
